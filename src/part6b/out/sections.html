Here are the results. Each agent pairs a frontier model with its native harness, or Codex if it has none. On the x axis, mean cost per task, log scale; on the y axis, pass rate. A task passes only if both the target behavior test and the preservation test pass. Cost is the prediction cost only.
Each logo is one agent, numbered by rank. Cost varies a lot: agents with similar pass rates differ in cost by more than 30 times, and Claude Opus 5 matches Claude Fable 5.1 at more than twice the cost.
The best agent, Grok 4.6 with Cursor, passes only 59.0% of tasks. Qwen 3.8 Flash follows at 57.5%, then three agents at 56.5%.
And 9 of 15 agents pass fewer than half of the tasks. Nearly all failures come from the target behavior test; preservation pass rates stay between 97.5 and 100%. Agents rarely break working features, but they often miss the bug they were asked to find.
Where do agents stumble?
Half the cases are lost before the bug is found
So where do agents stumble? We split each trajectory into five cumulative stages; each stage requires all the previous ones. GPT-5.6 Luna reads each trajectory and judges the first three stages; the last two come from the behavior tests. Each gray line is one agent, the black line is the average over 14 agents. Everyone starts at 100%.
First: did the agent even find the feature that contains the bug? On average only 75.4% of the time, from 63.5 to 91.4% across agents. For example, in the AbanteCart task Grok 4.6 fixes phone numbers, addresses and notifications on the profile page, but never tries the ID photo upload where the bug lives.
Second: did it identify the buggy behavior? This drops to 50.0%. Agents reach the feature but never run the interaction that exposes the bug, or they trigger it and don't recognize it as a bug. On Focalboard, all four agents we inspected reach the empty sidebar, and Claude Opus 5 even concludes it is intended, because the existing unit tests expect it.
Third: did it diagnose the root cause? 43.8%. A much smaller drop.
Fixing: once the cause is found, agents usually fix it. 41.0% pass the target behavior test.
And 40.8% also keep the existing behaviors working. Very few regressions.
So the two biggest drops are the first two stages: about 25 points lost before even finding the feature, and another 25 before identifying the buggy behavior. Half of all cases are gone before the agent has found the bug. Agents mostly fail at finding the bug, not at fixing it.
